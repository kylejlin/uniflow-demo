The Python modules are the authors' prototype, adapted for Python 3 using
2to3 (print statements and dictionary iteration). Its bundled pycparser
AST classes were regenerated using its own modified _ast_gen.py generator.
Translation rules have not deliberately been changed. bridge.py supplies
in-memory entry points in place of the file-editing/benchmarking CLI. Clang
performs preprocessing and type checking; declarations for malloc/memcpy
support the prototype's generated helper functions. This single-file demo
declines annotated function prototypes and preprocessor directives instead
of silently treating an incomplete translation as acceptance. Use function
definitions for #param/#return annotations. No original-source locations
are claimed for generated-code diagnostics.
