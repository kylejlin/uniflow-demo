          About these checks ⓘ
          

            
Supported input

            
Uniflow checks explicit flows against secrecy annotations in a subset of C. A passing result means no errors were found by Uniflow.

            
Supports integers, pointers, functions, casts, assignments, braced branches and loops, and #requires, #param, and #return annotations.

            
Arrays, structs, pointer arithmetic, function pointers, and preprocessor directives are unsupported. Flows conveyed only by choosing a branch are not tracked.

            
FlowNotation is the authors' Python prototype adapted to Python 3, checked with Clang in your browser. It has its own supported input and may be unable to check some Uniflow examples. Its compiler messages refer to translated code; it does not add squiggles.

            
Accepted means its compiler check completed without an alarm. Invalid input and failed translations are shown separately. Attribution and adaptation details.
